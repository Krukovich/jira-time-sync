Частые вопросы

Это бесплатно?
Да, полностью. MIT-лицензия, без подписок, без телеметрии. Код открыт на GitHub.
Куда уходят мои данные?
Никуда. Всё хранится локально: PostgreSQL (PGlite) в папке приложения, токен Jira — в системном хранилище (Keychain, DPAPI, libsecret).
Какие ОС поддерживаются?
Windows (.exe), macOS (.dmg) и Linux (.AppImage, .deb).
Работает ли с Jira Server?
На данный момент поддерживается Jira Cloud (API-токен + email). Поддержка Jira Server/Data Center (Personal Access Token) — в планах на v2.0.
Нужен ли интернет?
Для синхронизации задач и отправки worklog — да. Просматривать локальный кэш и работать с таймером можно офлайн.
Как сообщить о баге?
Открой Issue на GitHub с шагами воспроизведения.
